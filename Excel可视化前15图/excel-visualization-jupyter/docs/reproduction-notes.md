# 复刻说明

## 数据来源与读取

数据来自 `data/第二章 图表(前15).xlsx`，与用户提供的文件字节一致。每图直接读取对应编号的工作表，不使用随机数据替代原始数值。数据区域见仓库 README。

前 9 图及第 11—15 图使用 Excel 第 2 行作为表头，即 `header=1`；甘特图使用第 3 行作为表头，即 `header=2`。每图明确限定列和行数，避免右侧辅助对象、空列和说明文字进入数据表。

`src/chart_common.py` 从原 Excel 读取图表的矢量布局与文本框样式，包括绘图区位置、标题、字号、字体粗细和颜色。所有柱形、折线、圆环、水位及条纹均由代码绘制，没有粘贴原图作为输出。

## 关键实现

| 图表 | 实现 |
| --- | --- |
| 渐变柱形 | 逐柱生成渐变，柱高来自数据 |
| 均值柱形 | 从销售量计算均值，再绘制水平线 |
| 圆角柱形 | 圆角路径裁切渐变，以显示坐标控制圆角 |
| 标注柱形 | 独立商品色、同色标注背景与端点 |
| 层叠柱形 | 按原模板设置重叠比例，两系列均从零开始 |
| 销量蝴蝶图 | 重算占位，使左侧条形右端对齐 |
| 百分比蝴蝶图 | 根据完成率计算竖线数量，重建 REPT 条纹 |
| 数值百分比 | 销量、补齐区和同比标签区三段显示 |
| 对比柱形 | 从两年销量计算差值，添加比较线和差值标签 |
| 甘特图 | 开始日期定位、项目天数定长、完成度决定浅蓝长度 |
| 平滑折线 | 保形三次 Hermite 插值，经过全部原始点 |
| 菱形走势 | 根据原 XML 隐藏连接线，绘制空心菱形 |
| 对比折线 | 双系列、圆形节点、图例与高低错开的数据标签 |
| 单值圆环 | 按完成率绘制角度，内径沿用原 XML 的 90% |
| 水球图 | 圆形裁切矩形，水位和文字由完成率计算 |

## 与原图的差异

这是可重算的代码复刻，不能保证与 Excel 截图逐像素完全一致。

- 字体度量、换行和抗锯齿取决于系统与渲染器。优先使用微软雅黑，没有时使用随附思源黑体。
- 第 7 图的细竖线密度会随图片缩放变化。
- 第 11 图采用保形插值，与 Excel 内置平滑算法可能略有不同。
- 第 12 图按源文件的 `noFill` 设置保留无连接线效果。
- 第 14 图按源文件 `holeSize=90` 绘制，部分办公软件会将它渲染为更粗的环。
- 第 15 图以几何裁切替代 Excel 图片堆叠机制，局部边缘可能不同。

模板的标题、统计日期和结论文字保留原文。修改数据后，请同步核对这些文字及固定坐标轴上限。

## 验证范围

15 个绘图函数已使用 Python 3.12 和 Matplotlib Agg 后端逐一执行。已查看全部图表，并调整对比折线图的数据标签位置。另使用临时数据验证了柱高、均值线和水位会随数据改变，原始工作簿未修改。

Notebook 保存了实际 Python 执行产生的图形输出。验证环境没有安装 Jupyter 内核，未进行内核级“运行全部”测试；Notebook 中的 Python 代码逐格执行，后端选择魔法替换为 Agg。打开到 Jupyter 后使用 inline 后端。

GitHub 项目的路径逻辑支持从仓库根目录、notebooks 目录或外部目录调用脚本。GitHub Actions 配置使用同一套渲染与检查入口；尚未推送远程仓库或触发远程 CI。
