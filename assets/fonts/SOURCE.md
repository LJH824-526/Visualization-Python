# 字体来源

CourseReportSans是Noto Sans CJK SC的教学图表字符子集，已更改字体家族名称。原字体及派生字体遵循附带的SIL Open Font License 1.1。

原始来源：https://github.com/notofonts/noto-cjk
原文件：https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf

本子集仅覆盖当前图表代码的字符及拉丁字符；扩展新中文标签时请重新生成子集或安装完整版Noto中文字体。
