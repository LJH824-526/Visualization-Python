# 数据字典与表关系

主表`Orders`每行是一项订单商品明细，不是一张订单。原始共有21列，清洗后增加退货、区域负责人和派生指标。日期按源表的日历日期解析，不做时区换算。

| 字段 | 类型 | 含义与规则 |
|---|---|---|
| Row ID | 整数 | 明细唯一主键 |
| Order ID | 字符串 | 订单ID，可重复；统计频次须nunique |
| Order Date / Ship Date | 日期 | 下单/发货日期，后者不得早于前者 |
| Ship Mode | 类别 | 配送方式，不作为按时送达标签 |
| Customer ID | 字符串 | 客户ID，关联customers |
| Customer Name / Segment | 字符串 | 虚构客户名称/类型，ID映射一致 |
| Country/Region / City / State / Region | 字符串 | 国家地区、城市、州、销售区域 |
| Postal Code | 字符串 | 五位邮编，11个缺失标记UNKNOWN |
| Product ID | 字符串 | 商品ID，关联products |
| Category / Sub-Category | 类别 | 大类/子类，商品ID映射一致 |
| Product Name | 字符串 | 源名称，32个ID有多个名称，保留原值用于追溯 |
| Sales | 浮点 | 明细销售额，USD口径，必须正数 |
| Quantity | 整数 | 件数，必须正整数 |
| Discount | 浮点 | 折扣比例，0至1 |
| Profit | 浮点 | 源利润，可为负，不直接推定净利或毛利 |
| Returned | 布尔 | 订单出现在去重后的Returns中；不含退款金额 |
| Person | 字符串 | People按Region关联的区域负责人 |
| Year / Month | 年份整数/月字符串 | 月格式YYYY-MM |
| Margin | 浮点 | 单行Profit/Sales；总利润率重新按总额加权计算 |
| Ship Days | 整数 | 发货日期减订单日期，不等同运输耗时或到货时效 |
| Loss | 布尔 | Profit<0 |

`customers`主键Customer ID，`products`主键Product ID，去重`returns`主键Order ID，`People`主键Region。所有维表对Orders均为一对多；合并时主表方向使用`validate='many_to_one'`。SQLite提供orders/customers/products三个表，CSV另含returns，保留原始文件可追溯全部维表。
