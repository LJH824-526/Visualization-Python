# Superstore 离线经营大屏

直接打开“商业数据分析_离线大屏.html”即可查看与交互。数据、图表程序、样式和中文界面字体均已内置，不使用CDN，不需要联网、安装Python或启动Streamlit。

## 使用

1. 下载HTML，保存到电脑；如下载的是ZIP，请先解压。
2. 使用桌面版Edge、Chrome或Firefox打开HTML。请使用浏览器打开，不要用Word/WPS文字编辑器打开HTML。
3. 在顶部调整订单日期、区域、品类和客户类型；六张图、四项指标、经营观察及明细同步更新。“重置筛选”恢复全量数据。

全屏按钮用于演示；浏览器不允许网页全屏时，可用F11。普通窗口支持滚动，明细表位于图表下方。窄窗口自动改为分列排列。

## 交互与口径

| 组件 | 功能与口径 |
| --- | --- |
| 四项核心指标 | 销售额、利润、综合利润率、独立订单数；利润率为利润合计除以销售合计，订单按Order ID去重 |
| 月度经营趋势 | 当前条件按月汇总销售与利润，单位万USD；筛选日期之间的无交易月份显示0 |
| 品类销售结构 | 真实销售额份额；点击扇区筛选该品类，再点选中扇区恢复全部品类 |
| 区域规模与盈利 | 横轴销售额、纵轴利润，均为万USD；气泡面积与商品数量成正比；点击气泡筛选区域，再点恢复全部区域 |
| 子品类利润排名 | 单位千USD；亏损项保留，粉色表示负利润 |
| 客户销售贡献 | 销售与利润单位千USD；气泡面积与独立订单数成正比 |
| 折扣区间与利润率 | 各区间利润合计/销售合计，不是明细利润率的算术平均；分组为0、(0,20%]、(20%,40%]、(40%,100%] |
| 明细表和导出 | 每页20条；“导出筛选明细”包含当前条件下全部行及原清洗表28列，按日期倒序排列，使用UTF-8 BOM |

日期边界包含当天。空筛选和无效日期有明确提示，利润率显示“—”，不执行零分母计算。图表工具栏可缩放、复位并下载PNG；单图缩放不会改变顶部全局筛选条件。

## 数据与实现

数据直接取自用户上传“商业数据分析项目.zip”的data/clean/orders.csv，共9994条商品明细、5009个独立订单和793位客户，日期为2018-01-03至2021-12-30。全量销售2297200.8603 USD，利润286397.0217 USD，综合利润率12.4672%。

原始来源是Tableau Sample Superstore官方虚构零售教学样例；此页面是历史分析演示，不是实时经营系统。退货标记不等同于退款金额，折扣关联不代表因果。原始来源记录见data/provenance.json，不推定原始数据具有独立开放许可。

离线生成器使用Python打包；浏览器中的筛选、聚合和绘图由JavaScript与内嵌Plotly.js执行。这是原Python/Streamlit大屏的离线替代入口，未把浏览器端程序声称为纯Python运行。

已通过浏览器网页预览验证：全量指标、西部筛选、多条件筛选、空结果、无效日期、品类与区域图点击联动、明细分页及实际CSV下载。导出CSV已回读核对9994行、28列、UTF-8 BOM及销售额一致。预览浏览器限制file协议，因此没有声称已在该浏览器中实测本地file地址；静态检查确认HTML没有外部脚本和样式依赖，内容安全策略禁止网络连接。

## 重新生成

仅查看大屏时不需要运行代码。更换数据或修改样式时，在本目录终端执行：

```bash
python -m pip install -r requirements.txt
python build_offline.py
```

生成结果为dist/index.html，可改名后单独复制到其他电脑。输入文件data/orders.csv须保留现有字段和类型；src/dashboard.html为页面源代码。字体源文件和SIL许可附在data/内，Plotly.js保留其内嵌许可声明。

本次只生成离线文件，未上传GitHub或发布网站。
