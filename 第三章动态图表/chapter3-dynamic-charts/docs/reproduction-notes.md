# 复刻说明

## 来源和范围

项目仅对应“第三章 动态图表.xlsm”中的七组示例。原文件含八个工作表，其中“5 人力资源明细”是“5 透视表切片器”的数据源，不另算一张图。

所有绘图数据均从原材料提取。源文件的工作表、宏和公式没有被修改。项目不包含原始 xlsm，仅包含用于绘图的 CSV、样式参数和原文件校验记录。

## 动态逻辑

- 月份、周期选择直接从原始矩阵取数，图标题和数据使用同一选择，避免辅助标题缓存与实际图形不一致。
- 动态跑道图的默认值采用 Q5 的 4 月；源 I3 辅助表头为 1 月，而实际辅助数值与 4 月一致，代码按所选月份重算。
- 动态组合图真正显示或隐藏指标，未使用负数占位模拟隐藏；销售额和利润的零基线保持一致。
- 人力资源切片器的默认市场拓展匹配源透视表的整体平均值 6446.495。任意部门组合用分组收入合计/人数计算，保留总计的正确加权口径。
- VBA 玉玦图用 Python 周期按钮直接调用数据计算；不运行原始宏，不依赖工作簿外部链接。
- 滑珠图的月份/区域切换对应同一矩阵的两种读取方向，滑珠与轨道直接共用坐标，避免双轴错位。

## 样式与边界

保留源图主要图表类型、深蓝背景、系列配色和百分比含义。跑道、南丁格尔圆环、玉玦的内孔分别采用源 XML 的 45%、52%、35%。多层圆环的半径和标签使用几何重建，字体度量、抗锯齿、局部标签与控件位置可能与 Excel/WPS 不同，不保证逐像素相同。

原模板的标题、来源文字和历史日期保留原意。数据更新后应核对历史日期是否仍适用。动态图 1 的纵轴在新数据超过原 800 上限时自动扩展，避免六月销量被裁掉。

离线 HTML 是从 Python 函数计算并预生成的有限状态集合，选择时切换对应图像。它包含七图共 42 个状态；部门任意多选在 Notebook 中重新计算。更改 CSV 后需重建离线 HTML。

## 验证范围

七张默认图和 42 种离线状态已生成，检查了全部默认图的中文、数值和布局。测试覆盖月份、周期、多指标开关、部门均值、清空选择、矩阵转置及滑珠位置。

Notebook 的八个 Python 单元格已顺序执行并保存七个真实 PNG 输出。当前环境缺少 Jupyter 内核和 ipywidgets，使用 Matplotlib Agg 与静态回退分支验证；实时控件分支未在本地内核执行。GitHub Actions 配置后续内核执行，尚未推送或运行远程工作流。
